# Yet Another .. Metronome

**IN DEVELOPMENT**

A metronome web app exclusively for the use of ham fisted acoustic fingerstyle guitarists without any
appreciable musical ability who play a 20-something year old but nonetheless adored Taylor 310e and
need all the help they can get.
